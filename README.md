# Minecraft

A Minecraft-inspired 3D voxel game developed in Java using OpenGL.

## Features
- Voxel/block world system
- First-person camera movement
- Chunk rendering
- Custom shaders
- Character model (Steve)
- Texture atlas support
- Real-time 3D rendering

## Technologies Used
- Java
- OpenGL
- GLFW
- Maven
  
  ## Project Structure
- `Block` — block system
- `Chunk` — world chunk management
- `Camera` — first-person camera
- `Shader` — OpenGL shaders
- `TextureAtlas` — texture handling
- `GameEngine` — core engine logic
  
## Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Install Maven dependencies
4.Open the project files and run the main game file.
